# Portfolio Website

Portfolio site for Muhammad Ahmed Hassan, Data Engineer.

Static HTML, generated by one Node script with no dependencies.

```
npm run dev     # preview at http://localhost:4321, rebuilds on save
npm run build   # writes the finished site to dist/
```

Needs Node 20 or newer. No `npm install` step.

- Text lives in `content/`. One file per project in `content/projects/`.
- Styling is `src/styles.css`.
- The facts come from the career repo at `C:\Users\Admin\Desktop\My Career`.
  See `CLAUDE.md` for how the two fit together and the rules for what the site
  may claim.

To put it online, point any static host (Cloudflare Pages, Netlify, Vercel,
GitHub Pages) at this repo with build command `npm run build` and output folder
`dist`.
